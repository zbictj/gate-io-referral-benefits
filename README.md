## Що технічно робить реферальний код

Реферальний код — це набір символів (у цьому випадку `BVgVBl9c`), який Gate використовує, щоб визначити, хто вас запросив. Сам по собі код не купує підписку і не додає баланс. Він створює зв'язку між двома акаунтами, і від цієї зв'язки вже залежать усі бонуси.

Що з цього випливає на практиці:

- Зв'язка фіксується назавжди. Змінити або скасувати запрошувача після реєстрації не можна.
- Увести код заднім числом неможливо. Зареєструвалися без нього — бонусів за кодом не буде.
- Спроба обійти це через новий акаунт теж не працює. Gate відстежує повторну реєстрацію однієї й тієї ж особи (зокрема через KYC) і в такому разі скасовує реферальні права нового акаунта.
- Один користувач може створити до 50 власних кодів або посилань, кожен зі своїм відсотком.
- Суб-акаунти не запрошують самостійно, але їхній торговий обсяг зараховується головному акаунту.
